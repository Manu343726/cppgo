These are complete, buildable walkthroughs rather than reference material. The
first one binds a single function and shows the whole loop — annotate,
generate, implement the shim, call it. The second adds lifetime: a C++ object
behind an opaque handle, created and destroyed from Go. The third is about
throughput: when to pass a slice and when to batch, and why the answer is not
"always batch" any more.
