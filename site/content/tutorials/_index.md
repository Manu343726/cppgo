A tutorial is a lesson: you follow it from beginning to end and it works. It
assumes you write Go and know nothing about foreign function interfaces, so it
defines each term the first time it uses one.

Start with [Bind your first C++ class]({{< ref "tutorials/first-binding.md" >}})
if you have not run `cppgo` before.
