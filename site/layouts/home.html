Go → C++ · header-first

Call C++ from Go
without cgo.

No cgo. No import "C". No hand-written extern "C" layer. Point cppgo at your C++ headers and the compilation flags your build already uses. It generates the Go API, and it compiles the small C++ shim that carries the constructs the direct call cannot express. 

$ cppgo gen -header include/mathx/vector.hpp \
      -package mathx -library build/libmathx.so -out ./mathx

// the generated API
v, err := mathx.NewVector(3, 4)
defer v.Close()

n, err := v.Norm()

The numbers

Measured with the CPU pinned to 964 MHz and boost disabled, so the absolute nanoseconds are inflated by the clock. Cycles and ratios are the honest numbers.

pathns/op~cycles
plain Go indirect call 2.1 2 baseline
cppgo trampoline, direct 13.9 13 7.5x cheaper than cgo
cgo (same function, same dlopen'd symbol) 105 101

A call is not free. 13 cycles is not 2. It is close enough to a normal Go call that the boundary stops dictating your architecture. A stack switch, which is what the generated wrapper pays for the headroom guarantee, measured 14.9 ns (~14 cycles) on the same machine.

The trade-off is that the P stays with the goroutine during a direct call, so a foreign call in flight delays a GC cycle by up to its duration. A 2 ms call delayed the worst GC cycle by 1.1 ms, against 2.4 ms for a spinning Go goroutine. That is the right trade for short, compute-bound calls and the wrong one for calls that block.

The one-minute version

  1. Get the generator

    go install github.com/Manu343726/cppgo/cmd/cppgo@latest

  2. Point it at your header

    One -header per header to bind, -package for the Go package name, -library for the shared object your build already produces. Add -compile-commands so the parse uses the flags the build uses.

  3. Generate and call

    cppgo gen -header include/mathx/vector.hpp -package mathx \
    -library build/libmathx.so -out ./mathx
go test ./...

A construct the emitter cannot carry yet is refused at generation time, and the message names the file, the declaration and the fix. Everything the direct ABI cannot express goes through the generated shim instead.
