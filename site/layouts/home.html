Go → C++ · direct ABI

Call C++ from Go
without cgo.

No cgo. No import "C". No hand-written extern "C" layer. cppgo resolves your C++ declarations through libclang, mangles them with the Itanium ABI, and generates one NOSPLIT assembly trampoline per bound function — so a goroutine enters the System V C ABI directly, with this in RDI. 

//cppgo:library libmathx
//cppgo:header include/mathx/vector.hpp

//cppgo:class mathx::Vector
type Vector cppgo.Handle

//cppgo:ctor
func New(x, y float64) (Vector, error)

//cppgo:method norm
func (v Vector) Norm() float64

The numbers

Measured with the CPU pinned to 964 MHz and boost disabled, so the absolute nanoseconds are inflated by the clock — cycles and ratios are the honest numbers.

pathns/op~cycles
plain Go indirect call 2.1 2 baseline
cppgo trampoline, direct 13.9 13 7.5x cheaper than cgo
cgo (same function, same dlopen'd symbol) 105 101

A call is not free — 13 cycles is not 2 — but it is close enough to a normal Go call that the boundary stops dictating your architecture. A stack switch, which is what the generated wrapper pays for the headroom guarantee, measured 14.9 ns (~14 cycles) on the same machine.

The trade-off is that the P is not released during the call, so a foreign call in flight delays a GC cycle by up to its duration: a 2 ms call delayed the worst GC cycle by 1.1 ms, against 2.4 ms for a spinning Go goroutine. Right for short, compute-bound calls; wrong for calls that block.

The one-minute version

  1. Get the generator

    go install github.com/Manu343726/cppgo/cmd/cppgo@latest

  2. Annotate your Go declarations

    A //cppgo:library, a //cppgo:header, one //cppgo:class per mirrored C++ type, then one directive per binding.

  3. Generate and call

    cppgo gen -dir ./bindings/mathx
go test ./...

If a binding cannot work — the member is inline and has no symbol, it is virtual, it takes a std::string by value, or it returns a struct by value — the generator fails the build and says which of those it is. That is the point of the direct ABI mode: the failure happens at generation time, not as a segfault in production.
