Go → C++

Call C++ from Go
without cgo.

No cgo. No import "C". No C toolchain needed to build your Go side. cppgo generates one NOSPLIT assembly trampoline per bound function, so a goroutine enters the System V C ABI directly instead of going through the runtime's cgocall path. 

//cppgo:library libmathx
//cppgo:external dot
func Dot(a, b []float64) (float64, error)

The numbers

Measured on a Ryzen 7 6800HS with the CPU pinned to 964 MHz (power-saver profile), so the absolute nanoseconds are inflated roughly 4.5x by the clock — cycles and ratios are the honest numbers.

pathns/op~cycles
plain Go indirect call 2.1 2 baseline
cppgo trampoline 13.9 13 7.5x cheaper than cgo
cgo (same function, same dlopen'd symbol) 105 101

A call is not free — 13 cycles is not 2 — but it is close enough to a normal Go call that the boundary stops dictating your architecture. You no longer have to batch ten thousand rows into one call just to amortise the crossing.

Install in three steps

  1. Get the generator

    go install github.com/Manu343726/cppgo/cmd/cppgo@latest

  2. Annotate and generate

    //cppgo:library libmathx
//cppgo:external dot
func Dot(a, b []float64) (float64, error)
    cppgo gen -dir ./mathx

  3. Implement the shim, build your .so, open it

    #include "cppgo_shim.h"
extern "C" int32_t mathx_dot(const double *a, size_t an, const double *b, size_t bn, double *out) { ... }
